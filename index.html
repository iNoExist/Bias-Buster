Bias Buster Privacy Policy

Bias Buster helps users detect biased language and suggests neutral alternatives.

Data Collected

Only the text of the web pages you visit is sent to our API for analysis.

Purpose

To detect biased language and generate neutral suggestions.

Data Handling

No personal information is collected. Text data is processed temporarily on our servers and not stored permanently.

User Control

You can disable the extension at any time to prevent data from being sent.
